MCP

Layered rather than competing: MCP supplies access/transport, the context engine supplies synthesis, ranking, reconciliation and permission enforcement on top of it.; MCP is positioned as a lower plateau; a context engine is the superset that adds conflict resolution, ranking, and permissions the MCP layer lacks.
