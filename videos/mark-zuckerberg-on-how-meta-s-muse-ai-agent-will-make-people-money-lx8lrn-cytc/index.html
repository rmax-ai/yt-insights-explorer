3

Security and privacy concerns drive a shift from monolithic agents to partitioned architectures with specialized components like sentinel monitors and confidential VMs.

Before

Single agent with broad data access and permissions.

After

Core agent with sentinel monitoring agents, confidential VMs, and explicit approval gates.

Consequence

Improved security and privacy but increased system complexity and potential coordination overhead.
