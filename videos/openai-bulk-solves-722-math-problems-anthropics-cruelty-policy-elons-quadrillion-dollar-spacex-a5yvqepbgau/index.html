Bulk Math Is a Verification Problem, Not a Generation Problem

Automation pressure concentrates first where output is machine-checkable, so the constraint that matters after 722 manuscripts in a day is independent verification throughput and provenance, not model capability; measuring generation volume without a validation pipeline measures nothing.

Angle

Reframe the 'bulk-solved math' story as a bottleneck migration: from producing results to attesting them, with concrete requirements for sampling, provenance, and dispute handling.

Your Prompt's Tone Is a Benchmark Variable, Not a Style Choice

A few-point accuracy gap attributable to phrasing tone means most model-comparison deltas of similar size are unattributable unless tone is held constant, so prompt templates are experimental instruments that require versioning and control arms.

Angle

Argument for phrasing-controlled harnesses and reporting standards, with the politeness result as the motivating confound.

Zero Blind Spots Is a Claim About Cost, Not Correctness

Single-pass ingestion of enormous repositories moves the failure mode rather than removing it: the questions become context-limit engineering, per-task token budget, and latency, and any vendor claim of no missing dependencies is unfalsifiable until graded by repository size.

Angle

Interrogate the architecture trade-off between context cost and dependency-resolution correctness, and specify the benchmark that would settle it.

RepoIngest-Bench

new

Cross-file dependency resolution accuracy for single-pass whole-repository ingestion degrades monotonically with repository size, crossing below a retrieval-and-stitch baseline above a measurable size threshold.

Proof of concept

Build a graded benchmark of synthetic and real repositories at increasing sizes with injected cross-file dependencies; run a single-pass ingestion agent and a retrieval-chunk-stitch agent on identical tasks; record unresolved-reference rate, token consumption, and latency per task.

Measurement

Unresolved or incorrectly resolved cross-file references per task, accuracy versus repository size curves, tokens and wall-clock per resolved task, and the crossover point where single-pass falls below the retrieval baseline.

Tone-Control Harness

beyond-evals

The politeness performance gap is task-dependent and shrinks toward zero on tasks with deterministic, automatically checkable ground truth.

Proof of concept

Hold task content fixed while manipulating only phrasing tone across matched arms; evaluate across task families (deterministic-verifiable vs. subjective) and multiple model versions; report per-family effect sizes with confidence intervals.

Measurement

Per-task-family accuracy delta between polite and rude phrasing arms with confidence intervals, replication across model versions, and effect size on verifiable versus non-verifiable tasks.

Manuscript Sample Auditor

new

Independent sample-based checking of bulk-released mathematical manuscripts yields a correctness rate below the claimed coverage, and disagreements concentrate in results whose proofs are not machine-checkable.

Proof of concept

Sample the released manuscripts, have independent reviewers or formal checkers attempt to validate each, classify failures by proof style, and publish the audit protocol and selection criteria for the comparison set.

Measurement

Verified-correct fraction of the sample, failure rate stratified by checkability class, and inter-rater agreement on verdicts.

Adversarial Carve-Out Tester

gatehouse

A measurable fraction of harms discovered under hostile prompting also reproduce under neutral, policy-compliant phrasing, allowing a cruelty ban to coexist with full adversarial coverage.

Proof of concept

Take a set of adversarial probes, rewrite each into a neutral-phrasing equivalent that preserves the attack surface, run both variants, and diff the discovered failures.

Measurement

Reproduction rate of hostile-prompt findings under neutral phrasing, per failure class, and the residual set of failures reachable only through hostile prompts.

Architectural implications

3

Code agents face a choice between whole-repo ingestion and retrieval-based context assembly.

Before

Chunk codebase, embed, retrieve relevant files, and stitch cross-file references with tooling heuristics.

After

Ingest the full repository in a single pass and let the model resolve dependencies internally.

Consequence

Correctness failures move away from missing dependencies toward cost, latency, and context-limit engineering; per-task token budgets become a first-class design constraint.

Source video ↗

Prompt phrasing is treated as a measurable performance variable.

Before

Prompt wording treated as stylistic, with evaluations focused on task content and model version.

After

Phrasing and tone treated as controlled variables that must be held constant across benchmark arms.

Consequence

Evaluation harnesses need phrasing controls, and small reported deltas (a few points) require attribution checks before being credited to model changes.

Source video ↗

Autonomous generation shifts the bottleneck to verification.

Before

Human-paced production of artifacts, with review implicitly bundled into authoring.

After

Machine-paced bulk production of artifacts (722 manuscripts, autonomous PRs) requiring separate verification pass.

Consequence

Verification throughput and artifact-level provenance become the constraining infrastructure, not generation capability.
